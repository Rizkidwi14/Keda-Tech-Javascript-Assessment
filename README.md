### 1. Question 1
Buatlah fungsi dengan input array of number untuk mengurutkan angka dari terbesar ke terkecil dengan manual tanpa fungsi bawaan javascript

### 2. Question 2
Buatlah fungsi dengan input array of number dan number untuk menemukan jumlah maksimum subarray dengan panjang angka yang dimasukan ke fungsi

### 3. Question 3
Buatlah fungsi untuk mendapatkan jumlah semua bilangan genap dalam nested objek

## Technologies Used

- JavaScript
- Node.js
- Jest (Unit Testing)

## Installation

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd javascript-exercises
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

## Running Tests

Run all unit tests using:

```bash
npm test
```
